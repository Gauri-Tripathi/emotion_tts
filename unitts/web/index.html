    A quick start

    1. Choose a provider. Piper and eSpeak run on CPU. Hosted providers need a key and available credits.
    2. Write your script. Start with a short sentence. Import a .txt file for longer scripts.
    3. Make it yours. Pick a voice and a supported format. Adjust speed where available.
    4. Generate and listen. First requests can download models. Compare takes in the session library.
    5. Save the result. Download audio before refreshing or closing the page.

    Your full setup and command guide is in local-docs/USER_GUIDE.md on this machine.
